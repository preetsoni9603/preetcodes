My Calendar privacy

My Calendar is a personal planner at preetcodes.com/mycalendar, used only by its owner, Preet Soni. It is password protected.

What it stores

The tasks you add: name, department, dates, time, priority, reminder setting and notes. They are saved in a private file on this website's server and are not shared with anyone.

Google Calendar

If you connect Google Calendar, My Calendar asks for permission to view and edit events in your calendars (calendar.events). It uses this only to:

  • add, update and delete events for your own tasks, with reminders, and
  • show your existing events inside the planner.

Your Google sign-in token is kept in a private file on this server and is never sold, shared or used for anything else. My Calendar's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Click Disconnect in My Calendar's Settings, or remove "My Calendar" at myaccount.google.com/permissions.
